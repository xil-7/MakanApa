##1. Project Overview MakanApa is a static web application (HTML/CSS/JS) integrated with a Supabase database (PostgreSQL). This documentation details the steps to run the MakanApa application within a containerized environment using Docker (Nginx:alpine).

##2. System Prerequisites Before running the application, ensure your machine has the following installed:

Docker Desktop (v20.10.x or higher)

Git (v2.x or higher)
